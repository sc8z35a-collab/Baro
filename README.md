# BARO — HARBOR PROTOCOL

スマートフォンを横向きにして遊ぶ、オリジナルの3DタクティカルFPS。
海辺の研究港を舞台にした**シングルプレイヤー**ゲームです。VALORANT本体やRiot Gamesの素材・キャラクターは使用していません。

## 遊び方

**手軽に遊ぶ:** [`dist/Baro.html`](dist/Baro.html) をダウンロードしてブラウザーで開きます。3Dライブラリ、画像、音を含むすべての処理を1ファイルにまとめており、ゲーム実行中の外部通信はありません。

**ソースから起動:**

```sh
python3 -m http.server 8080
```

PCでは `http://localhost:8080`、同じWi-Fiのスマートフォンでは `http://PCのIPアドレス:8080` にアクセスします。静的ホスティングに置く場合は、リポジトリの `index.html` をルートにします。Sitesは使用していません。

「出撃する」のタップで全画面化と横画面ロックを要求します。利用できるかはブラウザーとOSの対応状況によります。対応しない環境でも横向きでプレイできます。

## 操作

| 操作 | スマートフォン | PC |
|---|---|---|
| 移動 | 左のスティック | WASD |
| 視点 | 右側をスワイプ | マウス |
| 射撃 | 大きい射撃ボタンを長押し。押しながら照準も可能 | 左クリック |
| ADS / スコープ | 照準ボタン | 右クリック / V |
| リロード | 装填ボタン | R |
| ジャンプ | 上矢印 | Space |
| ダッシュ | DASH | Shift |
| 範囲衝撃波 | PULSE | Q |
| 武器変更 | 右下の武器名 | B |
| 一時停止 | 右上のⅡ | Escape |
| 全画面 | 右上の⛶ | F |

移動・照準・射撃は同時入力に対応しています。設定では感度、音量、画質、エイム補助、振動を変更できます。ハイスコアと設定は端末内に保存します。

## 3つのモード

- **射撃訓練:** 静止ダミー、左右移動ダミー、浮遊ドローン、重装センチネル、ポップアップ、精密オーブ。撃破後に再出現します。被ダメージなし、時間制限なし。武器は自由に切り替えられます。
- **ウェーブ戦:** 全5ウェーブ。敵は障害物を回り込んで移動し、視線が通ったときに弾を発射します。ウェーブ間に体力とアーマーを補給します。
- **拠点制圧:** 4分以内にA・B・Cの中継器を制圧。中継器の近くに3秒留まってから、南ゲートへ戻るとクリアです。

緑色の補給ポイントは体力40・アーマー25を回復。20秒で再使用できます。DASHは5秒、PULSEは12秒で再使用できます。

## ステージ

中央コートと両側の回廊を接続した港湾研究区画。倉庫、研究棟、リアクター、制御小屋、海面、港のクレーン、遠景の街並みがあります。窓枠、排水口、路面標示、ドラム缶、木製リール、配管、電線、屋上空調、太陽光パネル、看板、ベンチ、植栽など1,200点以上の静的部品を配置しています。

建物の大部分は外観と遮蔽物です。全建物の内部探索やオンライン対戦は含みません。

## 実装と検証

ランタイムはThree.js r160とWeb Audio API。外部CDN、画像配信、APIキー、サーバー処理、課金要素はありません。シーンの静的部品とパーティクルはInstancedMeshでまとめ、静的な影はキャッシュします。高画質・バランス・軽量の3設定と、低FPS時の解像度調整があります。

```sh
npm install
npx playwright install chromium
npm run check
npm run build
npm test
```

`npm test` はスマートフォン横画面相当のChromiumで、射撃と撃破、装填、移動、壁衝突、全20武器の装備・発射、スコープ、一時停止、ジャンプ、アビリティ、敵AI、モード初期化、回転案内、オフライン版を確認します。実機の発熱やFPS、OSごとの全画面挙動は端末での確認が必要です。

- `src/game.js`: 操作、敵AI、戦闘、ゲーム進行
- `tools/build.cjs`: オフラインHTML生成
